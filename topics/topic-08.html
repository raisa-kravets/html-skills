Навчимося додавати зображення на вебсторінку

<img>, src, alt, шляхи до файлів і графічні формати.

Після теми ти зможеш самостійно написати правильний тег зображення та знайти типові помилки в ньому.

Як браузер показує зображення

Тег <img> можна уявити як рамку для фотографії.

<img>повідомляє: тут потрібно показати зображення
srcповідомляє, де знайти файл
altпояснює, що зображено
<img src="vinnytsia.jpg" alt="Вежа Артинова у Вінниці">

Браузер бачить <img> → читає src → знаходить файл → показує зображення.

Тег <img>

Для додавання зображення використовується тег <img>.

<img> — одиночний тег. Йому не потрібен закривальний тег.

НЕПРАВИЛЬНО
<img src="photo.jpg"></img>
ПРАВИЛЬНО
<img src="photo.jpg" alt="Опис зображення">

Вправа 1 — «Збери тег»

Натискай частини в правильному порядку.

Атрибути src, alt і width

src — джерело файла

src походить від слова source — джерело. Він повідомляє браузеру, де знаходиться файл.

<img src="tower.jpg" alt="Вежа Артинова">
src="tower.jpg"

Браузер шукає файл tower.jpg.

alt — текстовий опис

<img src="tower.jpg" alt="Вежа Артинова у Вінниці">

alt допомагає, якщо файл не завантажився, робить сторінку доступнішою та пояснює зміст зображення.

alt має відповідати на запитання: «Що важливого зображено на цій картинці?»

НЕВДАЛО

alt="картинка"
alt="фото"
alt="зображення"

КРАЩЕ

alt="Вежа Артинова у центрі Вінниці"

Базова ширина зображення

<img
    src="images/tower.jpg"
    alt="Вежа Артинова у Вінниці"
    width="500"
>

width="500" задає ширину зображення приблизно 500 пікселів. Пізніше розмірами й оформленням зображень керуватимемо за допомогою CSS.

Вправа 2 — «Що робить атрибут?»

Шлях до файла

1. Зображення поруч із HTML-файлом

project
├── index.html
└── tower.jpg
<img src="tower.jpg" alt="Вежа Артинова">

Файли лежать в одній папці, тому достатньо написати ім’я зображення.

2. Зображення в папці images

project
├── index.html
└── images
    └── tower.jpg
<img src="images/tower.jpg" alt="Вежа Артинова">

Читаємо так: «Зайди у папку images і знайди там файл tower.jpg».

3. Додатково: піднятися на папку вище

project
├── images
│   └── tower.jpg
└── pages
    └── about.html
<img src="../images/tower.jpg" alt="Вежа Артинова">

../ означає «піднятися на одну папку вище».

Назви файлів

РЕКОМЕНДОВАНО

vinnytsia-tower.jpg
central-park.webp
fountain.png

НЕ РЕКОМЕНДОВАНО

Моя фотографія Вінниці.jpg
Нове фото 1.jpg

Використовуй латинські літери, цифри й дефіс. Уникай пробілів.

Уважно до регістру: tower.jpg і Tower.jpg сервер може сприймати як різні файли.

Основні графічні формати

JPG / JPEGфотографії
PNGграфіка, прозорий фон
WebPсучасний формат для вебу, часто невеликий файл
SVGлоготипи, іконки, векторна графіка
GIFпрості анімовані зображення

JPG → фото · PNG → прозорість · WebP → веб · SVG → іконки та векторна графіка

    Типові помилки

    Умова для прикладів: HTML-файл index.html лежить у корені проєкту, а зображення — у папці images.

├── index.html
└── images
    ├── photo.jpg
    └── tower.jpg

    Мінішпаргалка

    <img
    src="шлях-до-файлу.jpg"
    alt="опис зображення"
>
    imgзображення
    srcде файл
    altщо зображено

    images/photo.jpg читаємо як: папка images → файл photo.jpg.

    Зображення серед інших HTML-елементів

    <h1>Вінниця</h1>

<p>Вінниця — місто на берегах Південного Бугу.</p>

<h2>Вежа Артинова</h2>

<img src="images/tower.jpg"
     alt="Вежа Артинова у центрі Вінниці"
     width="500">

<p>Вежа є одним із найвідоміших символів міста.</p>

    <img> можна використовувати разом з уже знайомими HTML-елементами.
