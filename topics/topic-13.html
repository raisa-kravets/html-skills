Що ти навчишся робити

Створювати форми, підписувати поля, обирати правильні типи введення та перевіряти обов’язкові дані.

1. Що таке HTML-форма?

HTML-форма — це частина вебсторінки, у якій користувач може вводити або вибирати інформацію. Форми потрібні для реєстрації, пошуку, опитувань, повідомлень і замовлень.

<form>
  <label for="name">Ім’я:</label>
  <input type="text" id="name" name="name">

  <button type="submit">Надіслати</button>
</form>

  • <form> — контейнер форми;
  • <label> — підпис поля;
  • <input> — поле введення;
  • <button> — кнопка.

2. Атрибути <form>

<form action="/send" method="post">
  • action указує, куди надсилати дані форми.
  • "/send" — приклад адреси. Англійське send означає «надіслати»; адреса може бути іншою.
  • method визначає спосіб передавання даних.
  • get додає дані до адреси сторінки.
  • post передає дані окремо від адреси сторінки.

У навчальних прикладах можна використовувати <form> без action і method. Для справжнього приймання та збереження даних потрібна відповідна програмна частина сайту.

3. Тег <input>

<input> використовується для введення даних або вибору варіантів. Атрибут type визначає тип елемента. Закривального тега він не має.

4. Тег <label>

<label> створює підпис поля. Значення for та id мають збігатися. Натисни підпис — курсор перейде у поле.

<label for="username">Твоє ім’я:</label>
<input type="text" id="username" name="username">

5. Основні атрибути полів

<label for="email">Електронна пошта:</label>
<input
  type="email"
  id="email"
  name="email"
  placeholder="Введи адресу"
  required
>
type — тип поля
id — унікальний ідентифікатор елемента, зокрема для зв’язку з підписом
name — назва даних поля під час надсилання
value — значення поля
placeholder — коротка підказка
required — обов’язкове поле

6. Перемикачі radio

Перемикачі дають вибрати один варіант із групи. Однаковий name об’єднує їх у групу.

<p>Формат заняття:</p>
<label><input type="radio" name="format" value="online"> Онлайн</label>
<label><input type="radio" name="format" value="offline"> У класі</label>

7. Прапорці checkbox

Прапорці дозволяють вибрати один або кілька варіантів.

<label><input type="checkbox" name="interests" value="html"> HTML</label>
<label><input type="checkbox" name="interests" value="css"> CSS</label>

8. Випадний список <select>

<select> створює список, а кожен <option> — окремий пункт.

<label for="course">Обери курс:</label>
<select id="course" name="course">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js">JavaScript</option>
</select>

9. Багаторядкове поле <textarea>

<textarea> призначений для довгого тексту й має закривальний тег. rows задає початкову кількість видимих рядків.

<label for="message">Повідомлення:</label>
<textarea id="message" name="message" rows="4" placeholder="Напиши повідомлення"></textarea>

10. Кнопка <button>

<button type="submit">Надіслати</button>
<button type="button">Натисни мене</button>

submit запускає надсилання форми. button — звичайна кнопка, яка сама нічого не надсилає.

11. Готова форма

Форма реєстрації на майстер-клас. Вона навчальна й не надсилає дані на сервер.

<form>
  <label for="student">Ім’я:</label>
  <input id="student" name="student" required>
  <label for="mail">Пошта:</label>
  <input type="email" id="mail" name="mail" required>
  <label for="level">Рівень:</label>
  <select id="level" name="level">
    <option value="beginner">Початковий</option>
    <option value="confident">Впевнений</option>
  </select>
  <label for="comment">Коментар:</label>
  <textarea id="comment" name="comment" rows="3"></textarea>
  <button type="submit">Зареєструватися</button>
</form>

    🚀 Наскрізний проєкт «Моє місто — Вінниця»
    Створюємо форму «Моя прогулянка Вінницею»
    На головній сторінці вже є розділ «Моя прогулянка Вінницею». Заміни його текст-заглушку HTML-формою, у якій відвідувач зможе поділитися враженнями від прогулянки містом.
    Не створюй нового <section> або <h2>. Використай наявний розділ, не змінюй попередні частини сайту й не додавай CSS або JavaScript.
    📁 Файли проєкту
    index.htmlabout.htmltower.htmleurope-square.htmlpirogov-museum.html
    У цій темі змінюй лише index.html. Інші чотири файли залиш без змін.
    
      
    1. Відкрий потрібний файл
    Відкрий index.html у Visual Studio Code. Знайди розділ із заголовком «Моя прогулянка Вінницею» та видали лише заглушку:
    <p>Цей блок буде доповнено під час вивчення форм.</p>
    Заголовок і тег <section> залиш без змін.
    
      
    2. Створи форму
    Під заголовком додай контейнер форми:
    <form method="get" action="">
</form>
    method="get" дозволяє побачити введені дані в адресі сторінки після надсилання. action="" надсилає форму на поточну сторінку. Серверне збереження тут не потрібне.
    
      
    3. Додай поле «Твоє ім’я»
    Створи підпис через <label> і текстове поле через <input type="text">. Додай for, id, name, placeholder і required. Значення for повинно збігатися з id. Назви id і name придумай самостійно.
    
      
    4. Додай випадний список
    Створи поле «Яке місце Вінниці тобі найбільше сподобалося?» за допомогою <select> і трьох <option>: Вежа Артинова, Європейська площа та Музей Пирогова. Додай підпис, а кожному варіанту — атрибут value.
    
      
    5. Додай дату прогулянки
    Створи поле «Дата прогулянки» через <input type="date">. Додай підпис, id і name.
    
      
    6. Додай перемикачі
    Після запитання «Ти вже був/була у Вінниці?» додай два <input type="radio">: «Так» і «Ні». Обидва перемикачі повинні мати однакове значення name, щоб можна було вибрати лише одну відповідь.
    
      
    7. Додай прапорці
    Після запитання «Що тобі цікаво у Вінниці?» додай три <input type="checkbox">: «Історичні пам’ятки», «Музеї», «Парки та прогулянки». Кожному прапорцю задай value. Користувач зможе вибрати кілька варіантів.
    
      
    8. Додай поле для відгуку
    Створи поле «Поділися враженнями» через <textarea>. Додай підпис, id, name, rows="4", короткий placeholder і закривальний тег </textarea>.
    
      
    9. Додай кнопку
    Наприкінці форми створи <button type="submit"> із текстом «Надіслати відгук».
    
      
    Структуру форми склади самостійно. Придумай коректні значення id, name і value, правильно розташуй елементи та перевір результат у браузері.

    1. Форма розміщена в потрібному розділі index.html.

    4. Поле імені є обов’язковим.

    8. Прапорці дозволяють обрати кілька варіантів.
