Навчимося створювати переліки, послідовності та вкладені списки

Коли потрібно записати кілька пов’язаних пунктів, їх зручно оформити списком.

У HTML вибір типу списку залежить не від того, як він виглядає, а від змісту інформації.

Вступна вправа — «Список чи не список?»

У яких випадках інформацію доцільно подати списком? Вибери всі правильні картки — можна вибрати кілька варіантів.

Невпорядкований список <ul>

Якщо порядок пунктів не має значення, використовуємо невпорядкований список <ul>.

HTML-код
<ul>
    <li>Ноутбук</li>
    <li>Навушники</li>
    <li>Мишка</li>
</ul>
Результат у браузері
  • Ноутбук
  • Навушники
  • Мишка

<ul> — створює весь невпорядкований список.
<li> — створює окремий пункт списку.

Усі <li> знаходяться ВСЕРЕДИНІ <ul>:
<ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
    <li>Пункт 3</li>
</ul>

Вправа 1 — «Збери список»

Розташуй рядки у правильному порядку. Використовуй перетягування або кнопки ↑ і ↓.

Пункт списку <li>

НЕПРАВИЛЬНО
<ul>
    HTML
    CSS
    JavaScript
</ul>
ПРАВИЛЬНО
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Кожен пункт списку потрібно оформити тегом <li>.

Впорядкований список <ol>

Якщо порядок пунктів важливий, використовуємо впорядкований список <ol>.

HTML-код
<h2>Як створити HTML-файл</h2>
<ol>
    <li>Відкрити редактор коду</li>
    <li>Створити новий файл</li>
    <li>Зберегти його як index.html</li>
    <li>Відкрити файл у браузері</li>
</ol>

  4. Відкрити файл у браузері

Вправа 2 — «UL чи OL?»

Списки + раніше вивчені теги

<h2>План на суботу</h2>
<ul>
    <li><strong>09:00</strong> — тренування</li>
    <li><strong>12:00</strong> — зустріч із друзями</li>
    <li><strong>16:00</strong> — виконати домашнє завдання</li>
</ul>
<h2>Три важливі правила</h2>
<ol>
    <li><strong>Зберігай</strong> файл перед перевіркою.</li>
    <li>Перевіряй <em>відкривальні та закривальні</em> теги.</li>
    <li>Не забувай про атрибут <strong>lang</strong>.</li>
</ol>

Вкладені списки

Один список може міститися всередині пункту іншого списку. Такий список називається вкладеним.

HTML-код
<ul>
    <li>Фрукти
        <ul>
            <li>Яблука</li>
            <li>Груші</li>
        </ul>
    </li>
    <li>Овочі
        <ul>
            <li>Морква</li>
            <li>Помідори</li>
        </ul>
    </li>
</ul>
Результат у браузері
  • Фрукти
    • Яблука
    • Груші
  • Овочі
    • Морква
    • Помідори
Фрукти
  ↳ Яблука
  ↳ Груші
Овочі
  ↳ Морква
  ↳ Помідори

ВАЖЛИВО: вкладений список розміщуємо всередині <li> батьківського списку.

    Список описів <dl>

    Якщо потрібно подати термін і його пояснення, використовуємо список описів.

    HTML-код
    <dl>
    <dt>HTML</dt>
    <dd>Мова розмітки вебсторінок.</dd>
    <dt>Тег</dt>
    <dd>Спеціальна конструкція HTML.</dd>
</dl>
    Результат
    HTML
    Мова розмітки вебсторінок.
    Тег
    Спеціальна конструкція HTML.

    <dl> — список описів.
    <dt> — термін.
    <dd> — опис або пояснення терміна.

    <dl>
    <dt>ТЕРМІН</dt>
    <dd>ПОЯСНЕННЯ</dd>
</dl>

    Вправа 5 — «Термін + пояснення»

    Доповни HTML-код: оформи назви HTML, Тег і Атрибут як терміни, а тексти після них — як відповідні пояснення. Використай теги <dt>, </dt>, <dd> і </dd>.

      Навчальна інфографіка «Списки в HTML»

      ЗАПАМ’ЯТАЙ

      • <ul> — список, у якому порядок пунктів не має значення.
      • <ol> — список, у якому порядок пунктів має значення.
      • <li> — окремий пункт списку.
      • Вкладений список розміщуємо всередині <li>.
      • <dl> — список описів.
      • <dt> — термін.
      • <dd> — пояснення терміна.

      Комплексна практична вправа «Мої цифрові інструменти»

      Створи фрагмент сторінки «Мої цифрові інструменти».

      1. Заголовок першого рівня.
      2. Вступний абзац.
      3. Заголовок другого рівня «Що я використовую».
      4. Невпорядкований список щонайменше з трьох пунктів.
      5. В одному з пунктів використай <strong>.
      6. Заголовок другого рівня «Як я створюю вебсторінку».
      7. Впорядкований список щонайменше з чотирьох пунктів.
      8. В одному з пунктів використай <em>.

        Меню — усі сторінки:

        index.htmlabout.htmltower.htmleurope.htmlpyrogov.html

        Списки у змісті: tower.html і europe.html.

        Сьогодні ти побачиш два практичні застосування списків: упорядкуєш реальні переліки в тексті та перебудуєш уже робоче меню з теми 6.

        На макеті «Місця» виглядає як один пункт меню. У HTML він матиме вкладений список із трьома наявними сторінками.

        Міні-вправа 1. Який список?

        Кілька цікавих фактів можна читати в будь-якому порядку. Який список доречний?

        Міні-вправа 2. Знайди помилку

        <ul>
  Вежа Артинова
  Європейська площа
  Музей Пирогова
</ul>
        Якого тега не вистачає для кожного пункту?

        Міні-вправа 3. Що вкладено в «Місця»?

        Які пункти мають бути у вкладеному списку?

        Частина 1. Упорядкуй зміст

        Приклад із підказкою — tower.html

        Розділ: «Цікаві факти» · Переглянути макет

        Зараз: «Висота вежі становить близько 28 метрів. На вежі встановлено годинник. Вежа була частиною першого міського водогону у Вінниці.»

        Завдання: кожен факт зроби окремим li усередині ul, адже порядок фактів не має значення. Не змінюй сам текст.

        Закріплення — europe.html

        Розділ: «Перенесення поховань» · Переглянути макет

        Етапи: «Дослідження», «Ексгумація», «Перепоховання», «Оновлення простору».

        Завдання: сам визнач тип списку. Врахуй, що етапи утворюють послідовність. Не перетворюй хронологію або «Основні відомості» на списки — ці блоки згодом стануть таблицями.

        Принцип вкладеного списку

        Вкладений ul завжди розміщуй усередині батьківського li:

        <ul>
  <li>Напої
    <ul>
      <li>Чай</li>
      <li>Кава</li>
    </ul>
  </li>
</ul>

        Перенеси цей принцип на пункт «Місця», але склади код меню самостійно.

        Частина 2. Перебудуй меню

        Було після теми 6: простий набір посилань. Треба отримати:

        Головна → index.html
        Про місто → about.html
        Місця:
        　Вежа Артинова → tower.html
        　Музей Пирогова → pyrogov.html
        　Європейська площа → europe.html

        Використай ul, li і вже створені посилання a. «Місця» — батьківський li, а вкладений ul із трьома сторінками має бути всередині нього. Не створюй places.html.

        <ul>
└─ <li>Місця
   └─ <ul>
      ├─ <li>Вежа Артинова…</li>
      ├─ <li>Музей Пирогова…</li>
      └─ <li>Європейська площа…</li>
      </ul>
   </li>
</ul>
        1. Спочатку перебудуй меню лише в index.html.
        2. Відкрий сторінку в браузері, перевір вкладеність і всі href.
        3. Лише після перевірки скопіюй однаковий блок у about.html, tower.html, pyrogov.html та europe.html.
        4. Переконайся, що якорі та посилання з теми 6 не зникли.

        Це поки не справжнє dropdown-меню: без CSS вкладений список постійно видно. Пізніше цей самий HTML стане випадаючим меню. Зараз не додавай CSS, JavaScript, nav або зображення.

        Перевір себе

        • Основне меню оформлене списком, і кожен пункт міститься в li.
        • «Місця» — окремий батьківський li із вкладеним ul.
        • У підменю рівно три потрібні сторінки з правильними href.
        • Я не створював places.html; меню однакове на всіх сторінках.
        • Усі посилання та якорі працюють.
        • Я не додавав CSS, JavaScript, nav або зображення.
        • Змістові переліки мають правильний тип списку, а майбутні таблиці не перетворені на списки.
        Результат:

        Посилання з теми 6 + структура списку → меню з вкладеним пунктом «Місця». Зараз підменю видно постійно; пізніше CSS перетворить його на випадаюче.
