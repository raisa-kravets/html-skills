Навчимося створювати переліки, послідовності та вкладені списки

Коли потрібно записати кілька пов’язаних пунктів, їх зручно оформити списком.

У HTML вибір типу списку залежить не від того, як він виглядає, а від змісту інформації.

Вступна вправа — «Список чи не список?»

У яких випадках інформацію доцільно подати списком? Вибери всі правильні картки — можна вибрати кілька варіантів.

Невпорядкований список <ul>

Якщо порядок пунктів не має значення, використовуємо невпорядкований список <ul>.

HTML-код
<ul>
    <li>Ноутбук</li>
    <li>Навушники</li>
    <li>Мишка</li>
</ul>
Результат у браузері
  • Ноутбук
  • Навушники
  • Мишка

<ul> — створює весь невпорядкований список.
<li> — створює окремий пункт списку.

Усі <li> знаходяться ВСЕРЕДИНІ <ul>:
<ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
    <li>Пункт 3</li>
</ul>

Вправа 1 — «Збери список»

Розташуй рядки у правильному порядку. Використовуй перетягування або кнопки ↑ і ↓.

Пункт списку <li>

НЕПРАВИЛЬНО
<ul>
    HTML
    CSS
    JavaScript
</ul>
ПРАВИЛЬНО
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Кожен пункт списку потрібно оформити тегом <li>.

Вправа 3 — «Знайди і виправ помилку»

<h2>Мої захоплення</h2>
<ul>
    <li>Малювання</li>
    Фотографія
    <li>Подорожі</li>
</ul>
Чому «Фотографія» оформлена неправильно?

Впорядкований список <ol>

Якщо порядок пунктів важливий, використовуємо впорядкований список <ol>.

HTML-код
<h2>Як створити HTML-файл</h2>
<ol>
    <li>Відкрити редактор коду</li>
    <li>Створити новий файл</li>
    <li>Зберегти його як index.html</li>
    <li>Відкрити файл у браузері</li>
</ol>

  2. Створити новий файл
  3. Зберегти його як index.html
  4. Відкрити файл у браузері

<ul>
порядок пунктів НЕ має значення

<ol>
порядок пунктів МАЄ значення

Вправа 2 — «UL чи OL?»

Списки + раніше вивчені теги

<h2>План на суботу</h2>
<ul>
    <li><strong>09:00</strong> — тренування</li>
    <li><strong>12:00</strong> — зустріч із друзями</li>
    <li><strong>16:00</strong> — виконати домашнє завдання</li>
</ul>
<h2>Три важливі правила</h2>
<ol>
    <li><strong>Зберігай</strong> файл перед перевіркою.</li>
    <li>Перевіряй <em>відкривальні та закривальні</em> теги.</li>
    <li>Не забувай про атрибут <strong>lang</strong>.</li>
</ol>

Вкладені списки

Один список може міститися всередині пункту іншого списку. Такий список називається вкладеним.

HTML-код
<ul>
    <li>Фрукти
        <ul>
            <li>Яблука</li>
            <li>Груші</li>
        </ul>
    </li>
    <li>Овочі
        <ul>
            <li>Морква</li>
            <li>Помідори</li>
        </ul>
    </li>
</ul>
Результат у браузері
  • Фрукти
    • Яблука
    • Груші
  • Овочі
    • Морква
    • Помідори
Фрукти
  ↳ Яблука
  ↳ Груші
Овочі
  ↳ Морква
  ↳ Помідори

ВАЖЛИВО: вкладений список розміщуємо всередині <li> батьківського списку.

    Список описів <dl>

    Якщо потрібно подати термін і його пояснення, використовуємо список описів.

    HTML-код
    <dl>
    <dt>HTML</dt>
    <dd>Мова розмітки вебсторінок.</dd>
    <dt>Тег</dt>
    <dd>Спеціальна конструкція HTML.</dd>
</dl>
    Результат
    HTML
    Мова розмітки вебсторінок.
    Тег
    Спеціальна конструкція HTML.

    <dl> — список описів.
    <dt> — термін.
    <dd> — опис або пояснення терміна.

    <dl>
    <dt>ТЕРМІН</dt>
    <dd>ПОЯСНЕННЯ</dd>
</dl>

    Вправа 5 — «Термін + пояснення»

    Доповни HTML-код: оформи назви HTML, Тег і Атрибут як терміни, а тексти після них — як відповідні пояснення. Використай теги <dt>, </dt>, <dd> і </dd>.

      Навчальна інфографіка «Списки в HTML»

      ЗАПАМ’ЯТАЙ

      • <ul> — список, у якому порядок пунктів не має значення.
      • <ol> — список, у якому порядок пунктів має значення.
      • <li> — окремий пункт списку.
      • Вкладений список розміщуємо всередині <li>.
      • <dl> — список описів.
      • <dt> — термін.
      • <dd> — пояснення терміна.

      Комплексна практична вправа «Мої цифрові інструменти»

      Створи фрагмент сторінки «Мої цифрові інструменти».

      1. Заголовок першого рівня.
      2. Вступний абзац.
      3. Заголовок другого рівня «Що я використовую».
      4. Невпорядкований список щонайменше з трьох пунктів.
      5. В одному з пунктів використай <strong>.
      6. Заголовок другого рівня «Як я створюю вебсторінку».
      7. Впорядкований список щонайменше з чотирьох пунктів.
      8. В одному з пунктів використай <em>.

        Перевір себе

        🚀 Наскрізний проєкт «Моє місто — Вінниця»

        Додаємо списки відповідно до макетів

        Продовжуй двосторінковий сайт із Теми 6. Не змінюй назви сторінок і не видаляй меню, тексти, якорі, зовнішнє посилання та email-посилання.

        На цьому етапі працюй лише зі списками. Картки, кольори, зображення, таблиці, відео, аудіо та форма з фінального макета з’являться у наступних темах.

        Етап 1. Оформи «Кілька фактів» на index.html

        У блоці «Кілька фактів» подай чотири пари «назва — значення» як список описів <dl>:

        Річка
        Південний Буг
        Область
        Вінницька
        Країна
        Україна
        Площа
        Вінниця становить 113,2 км².

        Для назв використовуй <dt>, для значень — <dd>.

        Етап 2. Оформи місця на index.html

        У розділі «Що варто побачити у Вінниці» заміни окремі абзаци одним маркованим списком. Кожен пункт має містити назву та короткий опис:

        • Вежа Артинова — символ міста, історична водонапірна вежа.
        • Європейська площа — сучасний громадський простір.
        • Національний музей-садиба М. І. Пирогова — унікальний музейний комплекс.
        • Вінницькі мури — залишки фортифікаційних споруд.

        Збережи в заголовку розділу id="places", щоб пункт меню «Місця» продовжував працювати.

        Етап 3. Оформи маршрут

        У розділі «Маршрут прогулянки містом» заміни текст зі стрілками впорядкованим списком:

        1. Європейська площа
        2. Вежа Артинова
        3. Вулиця Соборна
        4. Майдан Незалежності

        Збережи id="route". Порядок зупинок важливий, тому використовуй <ol>.

        Етап 4. Додай вкладений список «Цікаві місця»

        Після маршруту створи заголовок «Цікаві місця» і головний маркований список із двома пунктами. Усередині кожного пункту розмісти вкладений список:

        • У центрі міста
          • Вежа Артинова
          • Європейська площа
          • Вінницькі мури
        • Музеї
          • Музей-садиба М. І. Пирогова
          • Вінницький обласний краєзнавчий музей

        Вкладений <ul> має знаходитися всередині відповідного <li>.

        Етап 5. Оформи «Кілька фактів» на about.html

        На сторінці about.html у розділі «Кілька фактів» заміни абзац із переносами рядків таким самим списком описів, як на головній сторінці: Річка, Область, Країна, Площа.

        Збережи в заголовку id="facts", щоб внутрішнє посилання продовжувало працювати.

        Етап 6. Перевір навігацію та порядок блоків

        На обох сторінках залиш меню «Головна | Про місто | Місця | Маршрут». На about.html пункти «Місця» і «Маршрут» повинні вести на index.html#places та index.html#route.

        Не переміщуй «Дізнатися більше», посилання «На початок сторінки», «Повернутися на головну», дату й контакти автора. Дата та контакти мають залишатися останніми.
