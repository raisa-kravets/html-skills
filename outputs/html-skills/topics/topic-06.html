Гіперпосилання з’єднують сторінки

За допомогою посилання можна відкрити іншу сторінку сайту, інший сайт, файл або певне місце на сторінці.

Уяви сайт як будинок: сторінки — це кімнати, а гіперпосилання — двері між ними.

Тег <a> і атрибут href

HTML-код
<a href="about.html">Про місто</a>
Результат у браузері

Про місто

<a> створює посилання. href містить адресу переходу. Текст між тегами бачить і натискає користувач.

<aпочаток відкривального тега
hrefназва атрибута
"about.html"значення атрибута — адреса
Про містотекст посилання
</a>закривальний тег

Тег, атрибут, значення атрибута й текст посилання — різні частини одного HTML-елемента.

Абсолютні й відносні адреси

Абсолютна адреса

<a href="https://example.com">Інший сайт</a>

Містить повну вебадресу. Це як повна поштова адреса: місто, вулиця і будинок.

Відносна адреса

<a href="about.html">Про місто</a>

Вказує шлях від поточного файла. Ми вже знаємо, у якому «будинку» перебуваємо, тому називаємо потрібну «кімнату».

Відносні шляхи

about.htmlфайл у цій самій папці
pages/about.htmlфайл у вкладеній папці
../index.htmlспочатку на один рівень вище
../pages/about.htmlвище, а потім у папку pages

Шлях читаємо від файла, у якому записано посилання. Якщо файла за вказаним шляхом немає, перехід не спрацює.

Якірні посилання: перехід до місця на сторінці

Якірне посилання не обов’язково відкриває новий документ. Воно може прокрутити сторінку до конкретного елемента.

Для цього потрібні дві пов’язані частини:

1. Посилання містить #
<a href="#history">Історія міста</a>
2. Потрібний елемент має відповідний id
<h2 id="history">Історія міста</h2>

Як працює перехід:

натискання на посилання → браузер читає #history → шукає id="history" → прокручує сторінку до цього елемента.

Значення після # і значення id повинні повністю збігатися. Сам символ # у значенні id не пишуть.

Спробувати якірний перехід до прикладу ↑

Якір на іншій сторінці

<a href="about.html#history">Історія Вінниці</a>

Браузер виконає дві дії: спочатку відкриє about.html, потім знайде на ній елемент з id="history".

about.html — шлях до файла;

#history — адреса місця всередині цього файла.

Повернення на початок

<h1 id="top">Знайомство з Вінницею</h1>
...
<a href="#top">На початок сторінки</a>

Кожне значення id на сторінці має бути унікальним.

Інші можливості посилань

Нова вкладка й безпечний перехід

<a href="https://www.vmr.gov.ua/" target="_blank" rel="noopener">
    Вінницька міська рада
</a>

target="_blank" відкриває зовнішній ресурс у новій вкладці. Разом із ним використовуємо rel="noopener". Внутрішні переходи між сторінками власного сайту зазвичай залишаємо в поточній вкладці.

Посилання на електронну пошту

<a href="mailto:student@example.com">
    student@example.com
</a>

mailto: повідомляє браузеру, що потрібно запропонувати створення листа. Надсилання не відбувається автоматично.

Посилання для завантаження файла

<a href="files/material.pdf" download>Завантажити матеріал</a>

Атрибут download пропонує завантажити файл. Файл повинен існувати за адресою, указаною в href. У наскрізному проєкті цієї теми завантаження не використовується.

Інтерактивні вправи

Виконай вправи перед наскрізним проєктом. Після помилки зміни відповідь і перевір ще раз.

Вправа 1. З яких частин складається посилання?

Розглянь код <a href="about.html">Про місто</a>. Для кожної частини обери її призначення.

Вправа 2. Добери правильну адресу

Для кожної дії обери значення атрибута href. Уяви, що index.html і about.html лежать в одній папці.

Вправа 3. Створи посилання на другу сторінку

Напиши один HTML-елемент, який показує текст «Про місто» і відкриває файл about.html.

Вправа 4. Створи якірний перехід

На сторінці є заголовок розділу «Історія міста». Доповни обидва фрагменти так, щоб натискання на посилання переносило до цього заголовка.

Потрібна назва якоря: history.

Вправа 5. Безпечне зовнішнє посилання

Посилання на інший сайт має відкриватися в новій вкладці. Обери два потрібні атрибути.

Які записи потрібно додати до тега <a>?

Вправа 6. Знайди й виправ помилки

Учень хотів створити посилання «Написати автору», яке відкриває створення листа. Виправ код.

📁 Сьогодні працюємо з усіма сторінками сайту
index.htmlabout.htmltower.htmleurope.htmlpyrogov.html

Сьогодні вперше внеси однакову навігацію в усі сторінки, щоб п’ять окремих HTML-файлів стали одним сайтом. Тексти й структуру сторінок не переписуй.

Порівняй макети: меню повторюється на всіх сторінках, тому його HTML-код теж має бути однаковим. У цій темі важлива робота посилань, а не CSS-оформлення.

Міні-вправа 1. Що записати в href?

Файл сторінки Вежі називається tower.html. Яке значення потрібне в href?

Міні-вправа 2. Знайди помилку

<a href="tower">Вежа Артинова</a>
Чому посилання може не працювати?

🔗 Завдання 1. Створи спільне меню

Усі файли лежать в одній папці, тому в href достатньо імені файла. Відносний шлях працюватиме й після перенесення або публікації сайту. Не використовуй C:\..., file:///... чи інші повні локальні шляхи.

Пункт меню → HTML-файл

Головна → index.html
Про Вінницю → about.html
Вежа Артинова → tower.html
Європейська площа → europe.html
Музей Пирогова → pyrogov.html

  1. Відкрий index.html і створи перше посилання за прикладом: <a href="about.html">Про Вінницю</a>.
  2. Самостійно додай інші чотири пункти в указаному порядку.
  3. Перевір кожен href на головній сторінці.
  4. Скопіюй той самий блок у решту чотирьох файлів. Поточна сторінка також може залишатися посиланням.

Меню поки складається лише з посилань a. Не використовуй nav, ul, li або зображення.

🌐 Завдання 2. Додай одне зовнішнє посилання

У about.html знайди джерело «Вінницька міська рада — історія міста» й зроби його посиланням на https://www.vmr.gov.ua/. Воно має відкриватися в новій вкладці, тому використай вивчені target="_blank" і rel="noopener".

⚓ Завдання 3. Якірна навігація на about.html

Якорі додаємо лише на довгу сторінку «Про Вінницю». Використовуй значення id точно так, як подано нижче, і не вигадуй власних.

Якорі цієї сторінки

Витоки міста → origins
Походження назви → name-origin
Як змінювалася Вінниця → city-history
Основні історичні події → timeline
Джерела → sources

Один готовий приклад:

<h2 id="origins">Витоки міста</h2>
<a href="#origins">Перейти до витоків міста</a>

href="#origins" → id="origins". Для решти розділів сам додай задані id до заголовків і створи посилання з відповідними href="#...".

Заголовок має id="city-history". Яке значення href приведе до нього?

🔎 Перевір навігацію

Пройди маршрут: Головна → Про Вінницю → Вежа Артинова → Європейська площа → Музей Пирогова → Головна. Перевір також усі якорі в about.html та зовнішнє джерело.

Перевір себе

  • У мене є всі п’ять файлів і на кожній сторінці однакове меню.
  • Кожен пункт містить a, а href — правильне відносне ім’я файла.
  • У шляхах немає C:\... або file:///....
  • Для якорів використані лише задані id; у href="#..." є # і назви збігаються.
  • Я не використав nav, списки чи зображення завчасно.
  • Усі внутрішні, якірні й зовнішнє посилання працюють у браузері.
