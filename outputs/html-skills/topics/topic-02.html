Тема 2. Структура HTML-документа

HTML-сторінка — це не просто набір тегів. Вона має визначену структуру, яка допомагає браузеру правильно зрозуміти документ.

Учень уже міг написати:

<h1 title="Головний заголовок">Моя сторінка</h1>
<p>Це моя перша вебсторінка.</p>

Браузер може показати такий фрагмент. Але повний HTML-документ має власний каркас.

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Моя перша сторінка</title>
</head>
<body>
    <h1>Моя сторінка</h1>
    <p>Це моя перша вебсторінка.</p>
</body>
</html>

Теорія

З чого починається HTML-документ?

<!DOCTYPE html>

Цей запис повідомляє браузеру, що перед ним сучасний HTML-документ — HTML5.

<!DOCTYPE html> — не HTML-тег.

Це ніби позначка на документі, яка повідомляє браузеру, за якими правилами його читати.

<html> та lang

<html lang="uk">

</html>

Елемент <html> містить HTML-код документа.

lang — назва атрибута;

"uk" — значення атрибута.

Значення uk повідомляє, що основна мова документа — українська.

Інформацію про мову можуть використовувати браузери, пошукові системи та допоміжні технології, зокрема програми екранного доступу.

<head> і <body>

<html> │ ├── <head> │ інформація ПРО сторінку │ └── <body> те, що бачимо НА сторінці

HEAD = інформація ПРО сторінку

<head> містить службову інформацію про вебсторінку.

<head>
    <title>Моя перша сторінка</title>
</head>

BODY = вміст НА сторінці

У <body> розміщуємо основний вміст, який браузер показує на вебсторінці.

<body>
    <h1>Моя сторінка</h1>
    <p>Вітаю на моїй сторінці!</p>
</body>

Як влаштований HTML-документ

Подивись на схему: весь HTML-документ знаходиться всередині <html>, а його дві основні частини — <head> і <body>. Простеж, де розміщуються службова інформація та видимий вміст сторінки.

<title> — назва HTML-документа

<head>
    <title>Світ океанів</title>
</head>

<title> задає назву HTML-документа. Вона, зокрема, відображається на вкладці браузера.

вкладка: Світ океанів

Світ океанів

Океани займають...

<title> → назва документа / вкладка браузера.

<h1> → головний заголовок у вмісті вебсторінки.

Що таке метадані?

Метадані — це інформація про HTML-документ.

Прості приклади інформації: мова документа; назва документа; кодування символів.

<meta charset="UTF-8">

<meta charset="UTF-8"> задає кодування символів. UTF-8 допомагає браузеру правильно відображати українські літери та багато інших символів.

Розбір структури HTML-документа

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Світ океанів</title>
</head>
<body>
    <h1>Світ океанів</h1>
    <p>Океани займають більшу частину поверхні Землі.</p>
</body>
</html>
  • <!DOCTYPE html> → тип документа
  • <html lang="uk"> → HTML-документ, основна мова — українська
  • <head> → інформація про документ
  • <meta charset="UTF-8"> → кодування символів
  • <title> → назва документа
  • <body> → видимий вміст сторінки
  • <h1> → головний заголовок
  • <p> → абзац
